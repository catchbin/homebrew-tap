# homebrew-tap

> **catchbin is discontinued.** The project stopped on 2026-10-31 without launching. This repository is archived and kept for reference only. It is not maintained, and the `catchbin.io` service does not exist.

Homebrew tap for the catchbin CLI — a webhook inspector with persistence (permanent webhook URLs, captured-event inspection, replay, signature diagnostics).

## Install

The cask is disabled. `brew install catchbin/tap/catchbin` refuses with a "discontinued" message and downloads nothing. The archives from the final release, `v0.1.5`, remain on the [releases page](https://github.com/catchbin/cli/releases).

## What's in here

`Casks/catchbin.rb` — the Homebrew cask for the `catchbin` CLI, disabled since 2026-10-31.
